# Учтённый контекст

Источник: https://chatgpt.com/share/6ada46e0-6a50-83eb-9ff9-203b402d93d6

Общий разговор удалось прочитать после добавления его домена в сетевые настройки.
В нём есть разбор алфавита и быстрого письма, конспекты по русскому языку и физике,
уточнения обозначений и история сборки одного файла по исходным номерам страниц.

В приложении учтены:

- цикл «распознать → показать сомнения → получить исправления → подтвердить → экспортировать»;
- сохранение буквального «в момент x» после подтверждения пользователя;
- отдельная правка подписи вертикальной оси Y → X;
- подтверждённое раскрытие «тем» → «температура» с сохранением исходной записи;
- у старой страницы № 5 остаётся открытый вопрос, даже если № 6 подтверждена;
- неоднозначные индексы x/y/z и e/ℓ на странице с векторами остаются вопросами;
- при быстром письме т/m, похожие и/п/л, нижние петли д и у.

Четыре текстовые заметки загружаются в профиль один раз при первоначальном запуске
обычного приложения. Их можно изменить или удалить. Повторный запуск не восстанавливает
удалённые заметки. Это заметки по переписке, а не извлечённые пары изображений и не обучение.

Фотографии, старый DOCX и файлы из sandbox прежней беседы не перенесены. Текстовые
страницы из разговора не объявляются новыми проверенными страницами проекта.
Качество распознавания на почерке владельца в этой задаче не проверялось.
